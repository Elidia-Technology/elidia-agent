## Install

**Linux / macOS / WSL2**

```bash
curl -fsSL https://raw.githubusercontent.com/Elidia-Technology/elidia-agent/main/scripts/install.sh | bash
```

**Windows (native, PowerShell)** — *[details →](/user-guide/windows-native)*

```powershell
iex (irm https://raw.githubusercontent.com/Elidia-Technology/elidia-agent/main/scripts/install.ps1)
```

**Android (Termux)** — same curl one-liner as Linux; the installer auto-detects Termux.

See the full **[Installation Guide](/getting-started/installation)** for what the installer does, the per-user vs root layout, and Windows-specific notes.

:::tip Fastest path to a working agent
After installing, run `elidia setup --portal` — one OAuth covers a model plus all four Tool Gateway tools (web search, image generation, TTS, browser). See [Elidia Portal](/integrations/elidia-portal).
:::

## What is Elidia Agent?

Elidia Agent runs in your terminal and on messaging platforms, using the model provider you choose. It remembers across sessions, creates reusable skills, and can schedule routine tasks — and it runs wherever you need it: locally, in Docker, over SSH, or on serverless backends (Daytona, Modal).

## Key Features

- **Memory & skills** — remembers across sessions, creates reusable skills, and supports the [agentskills.io](https://agentskills.io) open standard
- **Flexible deployment** — 6 terminal backends: local, Docker, SSH, Daytona, Singularity, Modal. Daytona and Modal offer serverless persistence for on-demand wake
- **Lives where you do** — CLI, Telegram, Discord, Slack, WhatsApp, Signal, Matrix, Mattermost, Email, SMS, DingTalk, Feishu, WeCom, Weixin, QQ Bot, Yuanbao, BlueBubbles, Home Assistant, Microsoft Teams, Google Chat, and more — 20+ platforms from one gateway
- **Built by model trainers** — Created by [AiUtils](https://aiutils.io), the lab behind Elidia, Nomos, and Psyche. Works with [Elidia Portal](https://developer.aiutils.io), [OpenRouter](https://openrouter.ai), OpenAI, or any endpoint
- **Scheduled automations** — Built-in cron with delivery to any platform
- **Delegates & parallelizes** — Spawn isolated subagents for parallel workstreams. Programmatic Tool Calling via `execute_code` collapses multi-step pipelines into single inference calls
- **Open standard skills** — Compatible with [agentskills.io](https://agentskills.io). Skills are portable, shareable, and community-contributed via the Skills Hub
- **Full web control** — Search, extract, browse, vision, image generation, TTS — one subscription via [Elidia Portal](/integrations/elidia-portal) bundles all of them
- **MCP support** — Connect to any MCP server for extended tool capabilities
- **Research-ready** — Batch processing, trajectory export, RL training with Atropos. Built by [AiUtils](https://aiutils.io) — the lab behind Elidia, Nomos, and Psyche models
